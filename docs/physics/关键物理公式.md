# 关键物理公式（PHYSICS SUMMARY）

> 版本 v1.0 ｜ 对应交付物：`spectrometer-simulator.html` ｜ 上位依据：二维色散平面物理模型规范（PHYSICS v1）与需求规格（SPEC v3）
> 本文给出**当前代码实际使用**的公式与数值，并标注每条公式的落点（哪个模块、哪条断言）。
> 单位约定：长度 mm；波长在光栅方程中必须转 mm（`λmm = λnm × 1e−6`）；角度运算用 rad，界面显示 deg。

## 1. 坐标与机构（`geometry.js`）

```text
世界系：光栅中心 P=(0,0)，光栅面 x=0，面内切向 tg=(0,1)，指向元件侧法向 ng=(−1,0)，ng·tg=0
入射传播方向  i = (cosα, sinα)          准直镜 → 光栅
准直镜横向    tc = (−sinα, cosα)        i·tc = 0
设计出射方向  W = (−cosβ, −sinβ)        光栅 → 成像镜
成像/探测器横向 to = (−W_y, W_x) = (sinβ, −cosβ)

C  = P − Lc·i        准直镜中心        （Lc 独立于 fc）
S0 = C − fc·i        狭缝中心（准直镜前焦面）
M  = P + Lo·W        成像镜中心        （Lo 独立于 fo）
F  = M + fo·W        探测器面中心

四个平面：光栅 x=0；准直镜 (X−C)·i=0；成像镜 (X−M)·W=0；探测器 (X−F)·W=0
```

默认示例布局 `Lc=80 mm`、`Lo=60 mm` —— **是合成示例，不是官方机械实测尺寸**。

## 2. 设计求解（`design.js`）

```text
光栅方程     sinα + sinβ = m·N·λmm
两臂夹角     G = α − β          （只对设计中心波长定义）
设计角闭式解 sin(α − G/2) = m·N·λ0mm / (2 cos(G/2))
             α = G/2 + asin(m·N·λ0mm / (2cos(G/2)))，  β = α − G
```

求解时必须依次检查（对应 `STATUS` 枚举）：

| 检查 | 不通过时状态 |
|---|---|
| 反正弦自变量是否在 [−1,1] | `NO_REAL_SOLUTION` |
| `0 < α < 90°`（光栅物理前侧） | `BACKSIDE_OR_GRAZING` |
| `−90° < β < 90°` | `BACKSIDE_OR_GRAZING` |
| FIXED-α 模式反解出 `N > 0` | `NO_REAL_SOLUTION` |

两种上限不要混用：

```text
固定 G 设计上限   λ_design,max = (1 + cosG)/(m·N)      （α → 90° 的严格条件）
反正弦代数上限   λ_asin,max   = 2cos(G/2)/(m·N)        （仅代数定义域，不是物理上限）
固定 α 传播上限   λ_order,max  = (1 + sinα)/(m·N)      （红侧级次极限）
```

**固定 α 研究模式**：

```text
N_required = [sin(α_ref) + sin(α_ref − G)] / (m·λ0mm)
```
界面须提示「需更换光栅」——真实设备不能连续改刻线密度。

## 3. 各波长的衍射（不进降 α）

机构固定后，三波段**只**重求衍射方向：

```text
sinβ(λ) = m·N·λmm − sinα
β(λ)    = asin(m·N·λmm − sinα)          带符号，β<0 是合法的跨法向支路
W(λ)    = (−cosβ(λ), −sinβ(λ))
焦面位置 x(λ) = fo·tan[β(λ) − β(λ0)]    沿探测器横向
```

**禁止**按 λ 重新求解 α、禁止用 `2·fo`、禁止硬编码像移系数。

## 4. 逐面追迹（`trace.js`，实现 PHYSICS §5）

```text
① 狭缝 → 准直镜
   S = S0 + s·tc                       同一 s 的所有孔径光线共用该起点
   L = C + ζ·tc                        ζ 为入瞳横向采样坐标
   v0 = normalize(L − S)
   q_before = (v0·tc) / (v0·i)

② 理想薄透镜（傍轴局部斜率转移）
   q_col = q_before − ζ/fc
   v_col = normalize(i + q_col·tc)      同一 s 时与 ζ 无关 → 准直后平行

③ 准直镜 → 光栅面 x=0
   t_g = −L.x / v_col.x    （必须 > 0）
   Pg  = L + t_g·v_col     （Pg.x 显式置 0，其余残差单列上报）

④ 光栅切向波矢守恒 → 反射回 x<0
   u_y = v_col.y − m·N·λmm      |u_y| ≥ 1 → NO_PROPAGATING_ORDER
   v_g = (−√(1 − u_y²), u_y)

⑤ 光栅 → 成像镜平面
   t_q = [(M − Pg)·W] / (v_g·W)  （必须 > 0）
   Q   = Pg + t_q·v_g，  η = (Q − M)·to

⑥ 成像薄透镜
   q_before_o = (v_g·to)/(v_g·W)
   q_after_o  = q_before_o − η/fo
   v_o = normalize(W + q_after_o·to)

⑦ 成像镜 → 探测器面
   X = Q + t_x·v_o，  x_focal = (X − F)·to
```

### 4.1 两条核心不变量（值得记住）

**（a）孔径映射不变量**：中心狭缝点以入瞳偏移 `ζ` 入射时，其在光栅上的落点满足

```text
|Pg.y| = |ζ| / cosα       （与 Lc、fc 无关）
```
因此 **25 mm 光栅的接收条件**是 `|ζ| ≤ Wg·cosα/2`；默认参数下 `= 3.771044 mm`，
即 `D_eff = 2×3.771044 = 7.542088 mm` —— 与冻结基准逐位一致。这也是「为什么默认 D=10 mm 一定有渐晕」的答案。

**（b）像宽解析式**：狭缝像宽（薄透镜一阶）

```text
w_img = w · (fo/fc) · A          A = cosα/cosβ   （冻结的 anamorphic factor）
```
默认值 `0.010 × 1.5625 × 0.385170825111 = 6.018294142362 μm`，逐面追迹实测与之差 `< 1e−12 mm`。

> 注：`A` 与 `1/A` 分别描述「狭缝像」与「光束」，互为倒数。
> 光束变宽 `D_out/D_eff = 1/A = 2.596250637`；狭缝像缩小 `= A = 0.385170825`。表述时务必写明对象。

## 5. 口径与真实渐晕（`geometry.js` + `trace.js`）

```text
未截取光栅足印      W_footprint = D / cosα
轴上有效入射束径    D_eff = min(D, D_collimator, Wg·cosα)
实际照亮光栅宽度    W_illuminated = D_eff / cosα
衍射后束径          D_out = D_eff / A = D_eff·cosβ/cosα
有效 f/#（色散面）  f/# = fc / D_eff
```

**重要区分**：`D_eff` 是**轴上近似量**，用于展示与模式判断；
**逐条光线是否被裁切必须按各自真实落点判定**，首次越界即终止并给出 `CLIPPED_*`：

| 终止元件 | 判据 |
|---|---|
| 准直镜 | `|ζ| > D_collimator/2` |
| 光栅 | `|Pg.y| > Wg/2` |
| 成像镜 | `|η| > D_camera/2` |

理想不限口径模式：`apertures.*Half = null`，不裁切，并在界面明确标注「非真实仪器结果」。

空间向（z）：狭缝高 `h` 只通过 `h·fo/fc` 出现在焦面插图纵轴；**不进入色散面足印**，2D 模型不承诺空间向渐晕。

## 6. 色散、分辨力与采样（`metrics.js`）

```text
dβ/dλ = m·N·1e−6 / cosβ                 [rad/nm]    （α 固定）
dx/dλ = fo · dβ/dλ                      [mm/nm]
dλ/dx = 1 / (dx/dλ)                     [nm/mm]
采样  = 10·(p_um/1000) / (dx/dλ)         [Å/pixel]

R_slit   = (fc/w)·(tanα + sinβ/cosα)    理想几何狭缝极限
Δλ_slit  = λ0 / R_slit
R_grating(real) = m·N·W_illuminated      按**实际照亮**刻线数的 Rayleigh 极限
R_grating(ideal) = m·N·W_footprint       无限口径对比值，不是仪器指标
```

**禁止**把不同定义的宽度做无说明的方和根合成；官方经验值 `R ≈ 40000` 单列一行并注明「官方条件」。
