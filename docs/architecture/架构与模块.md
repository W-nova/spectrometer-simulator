# 架构与模块（ARCHITECTURE）

> 版本 v1.0 ｜ 对应交付物：`spectrometer-simulator.html`（16 个源文件内联而成）｜ 相关文档：[`../physics/关键物理公式.md`](../physics/关键物理公式.md)、[`../INDEX.md`](../INDEX.md)
> 一句话：**物理与显示严格分层**——`src/core` 不知道 Canvas 存在，`src/ui` 不构造任何光学交点。

## 1. 分层

```text
用户输入（滑条 / 数值框 / 单选）
        │  readUI()
        ▼
parseAndValidateInput ──► Input（mm / nm / μm / deg，越界即拒绝，不钳制）
        │
        ▼
   solveDesign ──────────► Solved（Object.freeze 深冻结：N、α、β、bands[]、单位向量）
        │
        ▼
   buildGeometry ────────► Geometry（S0 C P M F、四个平面、真实口径边界、光束预算）
        │
        ▼
   traceScene ───────────► Scene（每条光线的 RayResult：逐面交点、方向、状态、可见段）
        │
        ▼
   computeMetrics ───────► Metrics（色散、分辨力、采样、焦面、逐波段统计）
        │
        ├──► makeWorldToView  ──► 视图坐标 (u, v)     ← 只做显示，不改物理
        │            │
        │            ▼
        │      makeViewport   ──► 屏幕像素 (x_px, y_px)
        │            │
        │            ▼
        └──► makeRenderer     ──► 元件 / 光轴 / 光线 / 裁切叉 / 探测器
                     │
                     ▼
              panels.build    ──► 数值与公式面板（关键结果 / 展开公式）
              renderInset     ──► 焦面谱线插图（独立坐标系，不随主视图旋转）
```

**关键约束**：`Solved` 一经生成即深冻结，下游全部**只读**。这从结构上消除了旧版「面板用 `Nused`、追迹用 `CFG.N`」的状态撕裂。

## 2. 模块清单

| `constants.js` | 81 | 单位常量、默认输入、状态枚举 `STATUS`、容差 `TOL`、预警码 |

| `geometry.js` | 79 | `buildGeometry`：`C=P−Lc·i`、`S0=C−fc·i`、`M=P+Lo·W`、`F=M+fo·W`；四平面；真实口径；光束预算 |

### 2.3 `build/`

| 文件 | 职责 |
|---|---|
| `template.html` | HTML 骨架 + CSS + 面板/工具栏结构，含 `/*__INLINE_CORE__*/`、`/*__INLINE_UI__*/` 占位符 |
| `build.mjs` | 按固定顺序内联 16 个源文件 → 单文件 HTML；构建后**解析一遍内联脚本**并在存在外链时报错 |

内联顺序（不可打乱）：`constants → vec2 → validate → design → geometry → trace → metrics → assert → index`，
再 `style → projection → viewport → canvas → inset → panels → app`。每个文件都是 IIFE，
向 `globalThis.SoLExCore` 注册自己——**同一份源码既跑浏览器也跑 Node 测试**，不存在「测试版与交付版不同源」的风险。

## 3. 数据结构契约

```text
Input     : 校验后的用户输入（长度 mm、波长 nm、狭缝宽 μm、角度 deg）
Solved    : 深冻结。实际 N、α、β、G、三波段 β(λ)/W(λ)/x_focal、单位向量 i/tc/W/to/tg/ng、限制值与残差
Geometry  : S0 C P M F；planes{grating,collimator,camera,detector}；apertures{real|ideal}；beam{footprint,D_eff,W_illuminated,D_out,f#}
RayResult : S L Pg Q X、directions{in,collimated,diffracted,out}、residuals{...}、aperture{collimator,camera}
            status、firstStop、visibleSegments、visiblePolyline、x_focal、warnings
Scene     : bands[]{ band, ok, chief, aperture[], edges[], zetas }
Metrics   : 色散 / 分辨力 / 采样 / 焦面 / 逐波段统计（相机镜足印、透射与裁切计数）
```

三条渲染纪律：

1. **可见段与调试段分离**：`visiblePolyline` 只含真实存活的部分；画布只读它。
2. **裁切光线终止于首次截断点**：折线最后一个顶点就是真实交点，不继续画向探测器。
3. **画布不构造点**：元件端点来自 `Geometry`，光线端点来自 `RayResult`。

## 4. 显示投影（CR-VIEW-01 引入）

物理世界坐标保持不变（光栅面 `x=0`、切向 `(0,1)`、法向 `(−1,0)`）；在此之上插入一层**刚体变换**：

```text
i = normalize(P − C)        准直镜 → 光栅的入射主光线方向
t = (−i_y, i_x)             与其正交，指向屏幕下方
u(X) = (X − P)·i            v(X) = (X − P)·t          （单位 mm）
屏幕上：x_px = x0 + k·u      y_px = y0 + k·v          （k 为 x/y 统一比例，px/mm）
```

- 因 `i`、`t` 为正交单位向量，该变换是**旋转 + 平移**：距离、夹角、手性精确保持（断言到 1e−9 mm）。
- **没有第二次 y 翻面**：视图系本身 +v 向下；`viewport.toScreen` 只做线性映射。
- 每次求解后从当前 `Solved/Geometry` 重建，因此改 `G`、改 `N`、切换固定 α 模式都不会让光轴倾斜。
- 只有主视图走投影；**焦面插图使用自己的坐标系**，不随主视图旋转。

默认参数下的校验点（与 CR §3.3 一致）：

```text
(u,v) S = (−160.000, 0)      C = (−80.000, 0)      P = (0, 0)
      M = (−49.742, +33.552) F = (−153.372, +103.451)
W_view = (−cos G, +sin G) = (−0.829038, +0.559193)
```

## 5. 模块边界上的不变量

| 不变量 | 由谁保证 | 被谁验证 |
|---|---|---|
| 单位与量纲统一（mm / nm / rad） | `constants` + `validate` | 全部数值套件 |
| 一份快照驱动全链路 | `design` 深冻结 | Gate A1、Gate C |
| 光栅面固定 `x=0`、法向与切向正交 | `geometry` | `assertGeometry` |
| 同一狭缝点的孔径光线共用起点、准直后平行 | `trace` | Gate A2 |
| 首次真实截断即终止 | `trace` | Gate A2（含逐条「确实超出半口径」校验） |
| 折点必在真实元件面上 | `trace` + `canvas` | 逐面平面残差断言 |
| 显示不改物理 | `projection` + `viewport` | Gate V1（世界量快照比对） |
| 折叠公式不丢内容 | `app`（CSS 隐藏） | Gate V2（计算样式断言） |
